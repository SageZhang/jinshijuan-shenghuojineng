数据来源

配方经魔盒（JX3BOX）官方游戏数据接口实时抓取：
GET node.jx3box.com/manufactures?type=cooking|medicine|founding|tailoring&client=std
其中 锻造 的接口键为 founding；等级取 mode=simple 返回的 nLevel。
材料/成品名称通过 item_merged/id/5_{index} 还原，产物分类（剑 / 帽子 / 宴席 / 制品…）取 manufacture/belong。
行情价格来自魔盒交易行采样：GET next2.jx3box.com/api/item-price/{key}/detail?server=区服（单位铜，1 金 = 10000 铜）。
物品来源通过 item_merged 的 Desc 字段解析（「小提示：可以在菜贩商购买到」等）结合配方表判定。
抓取时间：，共 。RequireLevel = 255 的旧版配方没有等级门槛，等级列显示「—」，按「任意等级可做」参与计算。

计算口径

材料来源按游戏物品属性自动判定，不是按价格猜的：
  制 自制品／半成品 —— 本身有配方，成本按工本递归折算（最多 4 层）
  店 商店材料 —— 物品描述写明「可在××商人购买到」，用商店价（与交易行价分开存）
  行 交易行材料 —— 采集／掉落／无配方，用当前区服行情
  采 自采自得 —— 自己采集刷怪，按 0 金计（只花时间）
点材料旁的徽章即在该材料真实可用的来源间循环，价格随之切换（工本 / 商店价 / 行情 / 0）。
成本 = Σ 当前来源单价 × 数量。
期望收入 = Σ（产出概率 × 平均产量 × 售价 × (1 − 手续费)）。手续费默认 5%（交易行成交扣费），可在榜单页右上角调整；「·精」与失败产物已计入。
净利 = 期望收入 − 成本；单精力 = 净利 ÷ 精力消耗。
整体收益：在「收益排行」的次数列填生产次数，与「生产计划」联动，汇总总成本／总净收入／总净利／总精力／总经验；计划页还会把材料拆成「要买的」和「要自己做的」，自制中间品的批次、精力、经验一并计入。
定位划分：按「技能 + 魔盒产物分类」自动判定，不按名字猜。烹饪 → 小吃（回复/辅助/增强/特殊食品，宴席单列，烹饪材料归半成品）；医术 → 小药；锻造 → 装备（笔/棍/剑/枪/双兵/帽子/上衣/腰带/护手/鞋/马具…）、消耗品（磨石等）、制品归半成品；缝纫 → 装备（帽子/上衣/裤子/鞋/腰带/护手/背包）、制品归半成品。PVE 消耗品 = 小吃 + 小药 + 宴席 + 锻造消耗品。
在售件数 = 该物品交易行全部挂单数量之和。件数 < 10 的高价品属于「有价无市」，算出的利润率不能当作可兑现收益。
升级路径：对每个等级 L，在「等级 ≤ L 且材料已定价」的配方中按策略排序取最优，次数 = ⌈该级所需经验 ÷ 单次经验⌉，跨等级自动换配方，同配方连续区间合并展示。
注意：价格需与抓取数据同区服（std 重制版）。精力按「制作一次消耗」计，未含采集耗时。

已知偏差

· 经验需求曲线为估算，务必按游戏实际调整（升级页可逐级改）。
· 部分配方需专精 / 声望配方书，表格用 专精 标注，成本中未计配方书与专精投入。
· 商店价为 NPC 固定售价，魔盒未提供该字段，初始值暂用交易行价填充，请按游戏内实际售价改一次（改后与行情分开保存，重拉行情不会覆盖）。
· 产量为区间（如 2~3 个）时按期望值算，未考虑脸黑/脸白方差。
· 升级路径只算「制作成本」，未考虑市场容量：卤料、酱料这类材料型配方可能毛利率最高，但一次做几百组未必卖得掉，实际请结合交易行成交量取舍。
